Responsive CSS Cheat Sheet

Filters
Visual effects on elements, e.g. filter: grayscale(100%);
Media Queries
Apply styles by screen size, e.g. @media (max-width: 700px) { ... }
Responsive Design
Layouts that adapt to any device using fluid grids and flexible media.
Typography
Scalable text, e.g. font-size: clamp(1rem, 2vw, 1.5rem);
Flexbox
One-dimensional layout, e.g. display: flex;
Grid
Two-dimensional layout, e.g. display: grid;

Keep learning, keep building.
